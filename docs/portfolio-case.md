# InsightPilot · 可审批的数据分析 Agent

InsightPilot 面向需要快速复核 CSV 指标的产品和运营人员。用户可以先检查分组列、数值列和聚合方式，修正后再批准分析，并在刷新后回看结果及执行记录。

## 我的工作

基于 E2B Fragments 实现分析工作台、结构化计划、服务端审批、执行记录、结果核验和本地历史。保留原始项目的许可证及上游说明。用户将「按渠道汇总收入」改成「按渠道计算平均收入」时，服务端校验字段并生成新版 Python。保存后的新计划等待批准，旧凭证在同一服务进程中立即失效。

## 如何验收

- **可控执行**。用 24 行合成营销数据，把求和改成平均值。保存后页面显示「新版待批准」。批准后得到 **2,912.5**，历史恢复后仍显示这份结果及修改事件。[新版待批准](screenshots/round3-plan-reapproval.jpg) · [恢复后的报告](screenshots/round3-revised-result.jpg)
- **真实沙箱**。在另一轮合成数据验收中，DeepSeek 生成计划，E2B 执行 Python，应用使用 TypeScript 独立复算。求和结果为 **69,900**，四项校验通过，沙箱释放已确认。[真实执行记录](screenshots/live-execution-trace.jpg)
- **文件交付**。打开内置浏览器实际下载的 Markdown、CSV 和 Python，分别核对完整汇总、四个分组和代码预览。旧凭证、错误字段和并发审批纳入回归测试。[验收明细](verification.md)

录屏在 Chrome 中完成，使用合成 CSV。视频随作品集单独交付。
